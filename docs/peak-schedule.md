# 峰谷调度

工作台 → 设置 → 自动任务 → 峰谷调度（北京时间）。开关沿用 `peakValleyOnly`，默认关闭，已有开关状态不改变。

- `peakPeriods`：每行一段 `HH:MM-HH:MM`，允许跨午夜，起点包含、终点不包含。全天填 `00:00-24:00`。
- `peakWeekdays`：逗号分隔的 1–7，1 为周一。跨午夜时段由开始日决定；例外日期本身始终全天谷时。
- `peakOffDates`：每行一个 `YYYY-MM-DD`，用于配置节假日等全天谷时日期。日历不自动下载或更新。

默认时段参考 [DeepSeek 官方价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)（2026-11-11 核对）：北京时间周一至周五（不含中国法定节假日）09:00–12:00、14:00–18:00 为峰时，其余为谷时。默认星期为周一至周五；法定节假日需自行填写例外日期。第三方模型线路可自行修改规则。

规则在现有唯一调度器每个阶段开始前检查，统一限制自动浏览、评论守护和工作台成长素材采集。谷时恢复原间隔与额度，不积压、不补跑峰时跳过的轮次。旧的中午/夜间子开关不再作为执行规则。

这是启动限制，不是强制终止：已开始的轮次正常收尾；手动操作、主对话、直播、陪看制作以及独立成长插件的执行调度不受此开关控制。若需要严格保证峰时零模型请求，还需在各模型请求入口另设策略，不能靠杀掉进行中的评论任务实现。

非法配置保存时拒绝；若配置文件被直接改坏且限制已开启，调度保守暂停，并在设置页显示原因。既有记忆、队列、发送判重和任务所有权保持不变。

验证：`node --test test-peak-schedule.mjs test-character.mjs`；设置 API 回读测试使用 `node --import ./tools/register.mjs tools/test-peak-config.mjs`（需要 DSH 宿主依赖；只使用临时目录）。
